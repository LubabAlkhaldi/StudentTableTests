# 🎓 Student Table Tests Using Selenium

Automated testing project for a **student data table** built with **HTML** and **CSS**.  
Tests are implemented in **Java** using **Selenium WebDriver** and **TestNG** to interact with the table, filter rows, and extract data.

---

## 📖 About This Project

This project demonstrates a simple student table created with **HTML** and styled using **CSS** for clear presentation.  
The automated tests interact with this table on a local HTML file to:

- ✅ Print all rows where the student has passed (`Pass = Yes`)
- 🎲 Print data from a randomly selected column

It is a practical example of web table interaction using Selenium.

---

## 🛠️ Technologies Used

- 🌐 **HTML** — to create the structure of the student table  
- 🎨 **CSS** — for styling the table, including colors, borders, and layout  
- ☕ **Java** — programming language for writing automation tests  
- 🤖 **Selenium WebDriver** — to automate browser actions and interact with the web page  
- 📋 **TestNG** — testing framework to organize and run the tests
